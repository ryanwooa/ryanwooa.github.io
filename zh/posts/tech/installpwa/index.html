背景#

前段时间，老板告诉我说，我们的网页项目需要支持离线使用的功能，要让用户在没网的情况下也能使用部分功能。刚开始听到的时候，我还觉得好神奇，不是网页连不上服务器就会 404 了吗。

网上查了一下才知道一个叫 Service worker 的东西可以让网页缓存，当处于断网的时候，依然可以使用之前缓存的页面。 同时，这个东西还可以让网页像 APP 一样使用，用户可以吧网站添加到手机桌面，然后像 APP 一样打开。这就是 PWA。

PWA#

PWA（Progressive Web App，渐进式网页应用）是一种让网页像原生  App  一样体验的技术方案。

它本质上是“升级版的网页”，让你的网站具备以下能力：

  • 可以安装到手机主屏幕，像  App  一样打开
  • 支持离线访问（断网也能用部分功能）
  • 支持推送通知
  • 启动速度快，体验接近原生  App
  • 支持全屏、启动画面、图标等

PWA  的核心技术是Service Worker（服务工作线程）：

  • Service Worker 是浏览器后台的  JS  脚本，可以拦截网页的网络请求。
  • 它可以把网页的静态资源（HTML、JS、CSS、图片等）缓存到本地。
  • 当用户断网时，Service Worker  会用本地缓存的内容响应请求，实现离线访问。

PWA 的优势：

  • 跨平台: 同一套代码，PC、安卓、iOS  都能用。不用为了不同的平台写单端的程序代码
  • 无需上架应用商店: 用户直接用浏览器访问即可。
  • 自动更新: 每次上线新版本，用户下次访问自动获取。

怎么使用呢#

我的网站是用是 Next.js，那么我查了一下 next.js 的官网，也找了找 npm 网站，看看有什么好用的 Package。对于 nextjs， 有一个叫做 serwist/next 的 package，是一个比较早的支持 pwa 的 package，然后他有一些分支比如 @ducanh2912/next-pwa ，next-pwa 。 我就使用了@ducanh2912/next-pwa 。

安装了 package 之后，只需要配置上几个必须的文件就可以使用了。这里我就不说具体如何安装了，就说几个我觉得重要的东西吧。

最主要的文件就是 manifest 文件，他就和 app 的说明文件 app.json 一样，声明了一些比如APP名称，描述，尺寸，主题色，展示模式等内容。下面是一个例子

{
  "name": "PWA App",
  "short_name": "App",
  "icons": [
    {
      "src": "/icons/android-chrome-192x192.png",
      "sizes": "192x192",
      "type": "image/png",
      "purpose": "any maskable"
    },
    {
      "src": "/icons/android-chrome-384x384.png",
      "sizes": "384x384",
      "type": "image/png"
    },
    {
      "src": "/icons/icon-512x512.png",
      "sizes": "512x512",
      "type": "image/png"
    }
  ],
  "theme_color": "#FFFFFF",
  "background_color": "#FFFFFF",
  "start_url": "/",
  "display": "standalone",
  "orientation": "portrait"
}

第二个是在app/layout.tsx或者在pages/_app.tsx 添加 metadata，这是一个例子

import type { Metadata, Viewport } from "next";

const APP_NAME = "PWA App";
const APP_DEFAULT_TITLE = "My Awesome PWA App";
const APP_TITLE_TEMPLATE = "%s - PWA App";
const APP_DESCRIPTION = "Best PWA app in the world!";

export const metadata: Metadata = {
  applicationName: APP_NAME,
  title: {
    default: APP_DEFAULT_TITLE,
    template: APP_TITLE_TEMPLATE,
  },
  description: APP_DESCRIPTION,
  manifest: "/manifest.json",
  appleWebApp: {
    capable: true,
    statusBarStyle: "default",
    title: APP_DEFAULT_TITLE,
    // startUpImage: [],
  },
  formatDetection: {
    telephone: false,
  },
  openGraph: {
    type: "website",
    siteName: APP_NAME,
    title: {
      default: APP_DEFAULT_TITLE,
      template: APP_TITLE_TEMPLATE,
    },
    description: APP_DESCRIPTION,
  },
  twitter: {
    card: "summary",
    title: {
      default: APP_DEFAULT_TITLE,
      template: APP_TITLE_TEMPLATE,
    },
    description: APP_DESCRIPTION,
  },
};

export const viewport: Viewport = {
  themeColor: "#FFFFFF",
};

在这里可以设一些其他的东西，比如可以设置使用苹果手机的状态栏透明，就可以把内容显示在状态栏里面了。

离线功能#

为了实现离线使用的功能，需要配置 Runtime caching。 next-pwa 自定义了一写 caching 的配置，但是你可以配置你想要的。比如我需要缓存的网页都配置了进来。还有一些图片服务器的地址配置了进来，这样都用户离线的时候，就还是可以看到之前在线的时候缓存的图片。

const withPWA = require("@ducanh2912/next-pwa").default({
  // Your other options,
  extendDefaultRuntimeCaching: true,
  workboxOptions: {
    runtimeCaching: [
      // Your runtimeCaching array
    ],
  },
});

module.exports = withPWA({
  // Your Next.js config
});

添加网站到桌面#

  • 对于 iPhone 来说，在浏览器打开页面，然后在菜单中选择“把该页面添加到主页”就好。

  • 对于安卓设备来说，在选择“把该页面添加到主页”之后，有两个选项，一个是安装，另一个是添加书签。为了让他有 APP 一般的体验，需要选择安装。这样在手机上就能像 APP 一样访问网站了

总结#

总体来说 PWA 确实让我很惊艳。在配置他之后，我在 iphone 上可以像 APP 一般使用网站，不用看到浏览器的 UI，网站本身就占据了整个屏幕。通过修改网站的响应式设计等。完全可以让网站有和 APP 一样的体验，减少了开发成本。
