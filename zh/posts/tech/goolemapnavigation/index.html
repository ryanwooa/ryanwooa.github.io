Google Map JavaScript API 如何在谷歌地图上显示自定义导航路线

1. 背景#

在使用 GoogleMap JavaScript API 的时候，可能存在允许用户查询路线的场景。此时，如果想要在地图上添加导航路线，应该如何去做。

2. 相关知识点#

通过 Google Directions API, 可以获取到两个或者多个位置之间的导航信息，比如距离，时间，还有在地图上的路线等信息。通过把这些获取到的信息，传递给 Map JavaScript，就可以实现在嵌入的地图上显示导航路线了。

在使用谷歌地图和 Direction API 之前，需要在 Google Cloud Platform 中创建项目并开通对应功能的使用权限，并配置好账单。Google Cloud Platform 也自带一定额度的免费试用。

3. 如何实现导航路线的显示#

有两种方法可以实现这个功能

A. 直接使用 Map JavaScript 自带的 DirectionRender 来获取路线#

Map JavaScript 中自带DirectionRender功能，可以直接获取导航路线以及显示在地图上。可以参考一下代码

//假设已经有了google 地图 对象
const map = new window.google.maps.Map(mapRef.current, mapOptions);

//DirectionsService

function calculateAndDisplayRoute() {
  const directionsService = new google.maps.DirectionsService();

  //可以用自带的DirectionRender来显示路线，
  const directionsRenderer = new google.maps.DirectionsRenderer({
    suppressMarkers: true, // Hide default tags
    polylineOptions: {
      strokeColor: "#4285F4",
      strokeOpacity: 0.9,
      strokeWeight: 7,
    },
  });
  directionsRenderer.setMap(map);

  // Build the waypoints for the route (skip the first and last markers)
  const waypoints = objArray.slice(1, objArray.length - 1).map((marker) => ({
    location: new google.maps.LatLng(
      marker.locationInfo.location.lat,
      marker.locationInfo.location.lng
    ),
    stopover: true,
  }));

  directionsService.route(
    {
      origin: new google.maps.LatLng(
        objArray[0].locationInfo.location.lat,
        objArray[0].locationInfo.location.lng
      ), // Start point
      destination: new google.maps.LatLng(
        objArray[objArray.length - 1].locationInfo.location.lat,
        objArray[objArray.length - 1].locationInfo.location.lng
      ), // End point
      waypoints: waypoints, // Midpoints
      travelMode: google.maps.TravelMode.DRIVING, // an use DRIVING, WALKING, BICYCLING, TRANSIT
      region: "NZ",
      language: "en",
    },
    (response, status) => {
      if (status === "OK") {
        const navigation = {
          legs: response.routes[0].legs.map((leg) => ({
            distance: leg.distance,
            duration: leg.duration,
          })),
          overviewPolyline: response.routes[0].overview_polyline,
        };

        //直接用polyline来显示到地图上。
        const path = google.maps.geometry.encoding.decodePath(
          navigation.overviewPolyline
        );

        const polyline = new google.maps.Polyline({
          path: path, // 解码后的坐标点数组
          geodesic: true, // 路径是否为地理曲线
          strokeColor: "#4285F4", // 路径颜色
          strokeOpacity: 0.8, // 透明度
          strokeWeight: 7, // 路径宽度
        });
        polyline.setMap(map);

        // directionsRenderer.setDirections(response); // Render the route on the map
      } else {
        console.error("Directions request failed due to " + status);
      }
    }
  );
}

calculateAndDisplayRoute();

B. 使用 DirectionAPI 来获取路线数据#

  1. 使用 API： https://maps.googleapis.com/maps/api/directions/json 来进行查询，即可获取指定路线的导航数据
const url = createUrl({
  beginning: "https://maps.googleapis.com/maps/api/directions/json",
  searchParams: {
    ["origin"]: origin,
    ["destination"]: destination,
    ["waypoints"]: waypoints,
    ["mode"]: mode, // Can use DRIVING, WALKING, BICYCLING, TRANSIT
    ["region"]: "NZ",
    ["language"]: "en",
    ["key"]: apiKey,
  },
});

const response = await fetch(url);

if (!response.ok) {
  const errorData = await response.json();
  console.error("Error from Google Directions API:", errorData);
  return NextResponse.json(
    { message: "Failed to fetch directions", error: errorData },
    { status: response.status }
  );
}

const data = await response.json();
const navigation = {
  legs: data.routes[0].legs.map((leg) => ({
    distance: leg.distance,
    duration: leg.duration,
  })),
  overviewPolyline: data.routes[0].overview_polyline.points,
};

其中，legs 是分段信息，如果你有多个位置，他会将每一段数据存在一个 leg 中。overview_polyline 则是用于在地图上显示导航路线的路线数据。

  1. 在使用地图的时候，将导航数据传入地图，即可实现导航路线的显示
//先创建好Map对象
const map = new window.google.maps.Map(mapRef.current, mapOptions);

//可以限制按住Ctrl才能缩放
map.setOptions({
  gestureHandling: "cooperative", // Zoom in/out with Ctrl.
});

//设置Polyline路线
if (navigation.overviewPolyline) {
  const path = new google.maps.geometry.encoding.decodePath(
    navigation.overviewPolyline
  );
  const polyline = new google.maps.Polyline({
    path: path,
    geodesic: true,
    strokeColor: "#318156", // Google blue
    strokeOpacity: 0.9,
    strokeWeight: 6,
  });

  polyline.setMap(map);
}

总结#

两中方法都可以实现导航路线的加载，他们分别使用与不同的情况。A 方法适用于实时查询导航路线并加载的场景。如果你不需要每次都重新查询路线，可以使用 B 方法。将查询 API 独立使用，并把路线数据储存在数据库中。在需要使用的时候直接读取数据库，避免了反复调用 DirectionAPI 造成的费用问题。
